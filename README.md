# Garmin Running Dashboard

Локальный веб-дашборд для истории пробежек из Garmin Connect. Backend читает данные через read-only MCP-адаптер, который использует официальный Garmin Connect Personal API.

## Подключение

1. Войди в [Garmin Connect](https://connect.garmin.com/) и создай Personal API key по [инструкции Garmin](https://developer.garmin.com/gc-developer-program/personal/personal-api/). Garmin показывает ключ только один раз.
2. Скопируй `.env.example` в `.env` и добавь Garmin key в `GARMIN_PERSONAL_API_KEY`. GigaChat необязателен: чтобы включить тренера, добавь ключ в `GIGACHAT_AUTH_KEY` и выставь `COACH_ENABLED=true`.
3. Запусти `docker compose up --build`.
4. Открой <http://localhost:8080> и нажми **Синхронизировать**.

Не вставляй ключи в чат и не добавляй настоящий `.env` в Git. Garmin API key и bearer-token cache остаются на этой машине. Бэкенд хранит локальные сводки тренировок. При выборе пробежки MCP по запросу скачивает её FIT-файл, разбирает точки в памяти и возвращает графики; сам файл и точки на диск не записываются. ИИ-тренер по умолчанию выключен; при включении он отправляет сводки выбранного и предыдущего периода в GigaChat API.

ИИ-тренер работает через GigaChat API. Создай проект в [личном кабинете GigaChat API](https://developers.sber.ru/studio/), скопируй ключ авторизации и помести его в `.env` как `GIGACHAT_AUTH_KEY`. Для физлица используется scope `GIGACHAT_API_PERS`; модель по умолчанию — `GigaChat-2` (Lite). Backend сам получает и обновляет OAuth access token; его не нужно вручную помещать в `.env`. Скачай [корневой сертификат Минцифры по инструкции Сбера](https://developers.sber.ru/docs/ru/gigachat/certificates) и положи в `certs/russian_trusted_root_ca_pem.crt`; Docker передаст его backend-контейнеру.

## Безопасность

Compose публикует веб-интерфейс только на `127.0.0.1:8080`. Nginx проксирует `/api` без авторизации, поэтому не меняй привязку порта на публичный интерфейс и не выставляй сервис в интернет без авторизации или приватной сети.

## Сейчас

- Ручная синхронизация пробежек за последний год.
- Показатели дистанции, частоты, времени, среднего темпа и пульса за неделю или месяц.
- График километража по неделям и простой список последних пробежек.
- Три переключаемых варианта дашборда и отдельный калькулятор темпа со сплитами.
- Прокручиваемый календарь тренировок, график недельной дистанции, темпа и пульса, быстрый переход по месяцам.
- Детальный график километрового темпа в выбранной тренировке, если интервалы доступны в ответе Garmin.
- ИИ-саммари выбранного периода и чат по беговой истории при настроенном `GIGACHAT_AUTH_KEY`.

Структура фронтенда описана в [ARCHITECTURE.md](frontend/ARCHITECTURE.md).

Интерфейс read-only: он не загружает тренировки и не меняет данные Garmin Connect.
